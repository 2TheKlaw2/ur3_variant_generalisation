# Stage 5: Static V1–V5 scene in RViz (no motion)

Kinematic/geometric simulation only. These are not physical results.

## Run
```bash
cd ~/ros2_ws && colcon build --symlink-install --packages-select ur3_variant_generalisation && source install/setup.bash
ros2 launch ur3_variant_generalisation view_variant_scene.launch.py                         # home pose
ros2 launch ur3_variant_generalisation view_variant_scene.launch.py pose:=v1_pickup_V1_geometry gripper_width:=0.0082
```
The robot uses the lab calibration (`config/ur3e_lab_calibration.yaml`). Joints come from any file in `config/saved_poses/`.

## What is where
| File | Purpose |
|---|---|
| `cad/` | Z-up mm meshes, `manifest.yaml` (poses in plate frames), `CAD_CHECKS.md`, STEP sources, regeneration tools |
| `config/scene/scene_registration.yaml` | Plate-to-`base` transforms (PROVISIONAL), generated by `scripts/scene/compute_scene_registration.py` |
| `urdf/variant_scene.urdf.xacro` | Separate scene description, rooted at `base`, published in `/scene` |
| `launch/view_variant_scene.launch.py`, `rviz/variant_scene.rviz` | Robot + scene viewer |
| `scripts/scene/validate_scene.py` | Offline checks + `results/scene_check/` |

## Registration (how the plates were placed)
- **Pickup plate:** 2D rigid fit of the five measured pickup TCPs to the CAD pocket centres. Yaw −178.96°, RMS 2.1 mm (mostly perpendicular scatter of where the TCP sat on each block).
- **Placement plate:** V1 axis = `v1_insertion_end` TCP xy. Yaw **assumed** parallel to the pickup plate (one point gives no yaw; the photo supports parallel rows).
- **Heights (corrected 30 Oct):**
  - The robot base sits on the trolley top (z = 0).
  - The blue plates sit on a slotted aluminium fixture plate, 12.5 mm thick (from the ur3_lfd trolley mesh; not yet measured on the real plate), so their undersides are at z = 12.5 mm.
  - Re-run `compute_scene_registration.py --fixture-thickness <m>` to change it.
  - `fixture_plate` and `trolley_top` collision boxes are generated in `cad/environment/`.
  - See the Stage 8 doc, "Scene height correction".

## Validation (`results/scene_check/scene_check.txt`, 72 checks)
- All 12 mesh sizes match CAD. Parts rest on the 1.0 mm pocket floor; fittings rest on the 3.0 mm plate top.
- V1→V5 run left to right from the robot side on both plates (decreasing base x), matching the lab photo.
- UR3e+RG2 FK from the lab calibration reproduces all 11 recorded `gripper_tcp` poses within 0.03 mm.
- At every measured pickup pose, the RG2 closes across the 10 mm faces of the grip block (≤2.4°). The fingers stay ≥22 mm from neighbouring parts and ≥16 mm from the plate, open (40 mm) or gripped (8.2 mm).
- Tab axis of the picked part is parallel to the fitting slot axis, so no yaw change is needed before insertion.
- Insertion-ready TCP is 0.3 mm from the fitting V1 axis. The implied seated depth is 0.65 mm above the CAD floor. Measured rotation is −25.1° (CW) vs the CAD stop at 26°.
- **Known, accepted:** revised V4/V5 tabs (5.18 mm) are wider than the pickup pocket notches (4.90 mm), ~0.14 mm overlap per side. Pocket collisions for V4/V5 are out of scope.

## Known limits
- Trolley mesh (from ur3_lfd, read-only) is off by default; `show_trolley:=true` shows it at `0 -0.2 -1.047` in `base`.
- Scene objects are not yet in the MoveIt planning scene. That is the next step, with attach/detach and an ACM for resting and seating contacts.
- `config/pickup_plate.csv` / `placement_plate.csv` still list V5 at +5 mm. The CAD and confirmed geometry give +15 mm. They are left unchanged because the C++ tests read them.

## Plate revision (30 Oct 2026): prongs as a mechanical datum

Both base plates were redesigned (`Basea.STL`, `PlaceAssem.STL`): 141 mm wide (was 70 mm), with two prongs on the side
away from the robot that butt against the far edge of the aluminium top layer, plus pocket fillets (≤0.35 mm).
Pocket and fitting positions in the plate frame are unchanged (fittings match the manifest exactly), so the existing
robot-taught poses and registration still apply. The prongs set plate yaw/parallelism mechanically.

Prong length ≈71 mm beyond the old far edge, but the far-edge gap measured in the current lab setup is 76–77 mm:
with the prongs butted against the edge, the plates should sit ~5.5 mm farther from the robot than the current
registration. The simulation keeps the measured registration until the lab calibration (`CALIBRATE_PLATES`) re-measures it.
Scene validation: 63 checks, 1 FAIL (the known V4 part-in-pocket notch contact).
